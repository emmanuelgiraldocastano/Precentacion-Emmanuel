Juegos de Ciberseguridad

Lenguajes: Python

Descripción general:

Este proyecto se enfoca en reforzar conceptos de lógica y ciberseguridad mediante 3 minijuegos interactivos integrados:

  • Adivina el número: El sistema ofrece pistas para descifrar un número secreto.
  • Verdadero o Falso: Preguntas de opción lógica sobre seguridad de datos.
  • Secuencia numérica: Desafío de ordenamiento y secuencias de números enteros.

* Proyecto enfocado en la lógica de programación.
